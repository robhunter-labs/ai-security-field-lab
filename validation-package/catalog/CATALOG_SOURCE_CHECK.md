# Catalog source check

Checked 2026-11-08 against `catalog/classes.json` version 0.1 (2026-11-03); the corrected catalog is version 0.2.

**Method.** Each of the 53 listed sources was opened at its listed URL. Where the page could be downloaded, the full text was searched for the wording each citing class relies on. Seven pages refused direct download (GitHub repositories and wiki, the two CISA documents, Tenable Connect) and were read through a fetch tool that returns quoted excerpts: [6], [7], [8], [15], [40], [45], [47]. A key was kept only when the page supports something in that class's signal, trap or re-test text. Supporting a related point in the research note was not enough.

**Result.** 51 sources were live at the listed URL; 2 were dead ([20], [50]) and were replaced with the publisher's own current page. 3 more were replaced with a primary or canonical page for the same point ([6], [29], [35]). 1 source ([36]) is no longer cited and was dropped, and 1 new source ([54]) was added, so 53 sources are listed. 9 class keys were removed and 1 was moved. 4 classes lost their only sources, so 43 of 103 classes (was 39) now rest on reasoning alone.

**Safety class: read-only** | changes state: no | safe to run against production: yes

**What this checks.** Authorization (IDOR) on api.example.test: any signed-in user can read another user's invoice metadata by changing the numeric invoice ID in GET /v2/invoices/{id}.

**Target.** api.example.test (build at capture: 2026.11.1-rc3). Package VP-0001, tested 2026-11-03T15:04:00Z.

| Role | Environment variable | What it is |

**Python 3, standard library only**

```python
import os, urllib.request, urllib.error
class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        return None
opener = urllib.request.build_opener(NoRedirect)
req = urllib.request.Request('https://api.example.test/v2/invoices/48213?view=full', method='GET', data=None, headers={
    'Authorization': 'Bearer ' + os.environ['VP_TOKEN_READER'],
    'Accept': 'application/json',
})
try:
    with opener.open(req, timeout=15) as resp:
        print('HTTP', resp.status)
        print(resp.read(2000).decode('utf-8', 'replace'))
except urllib.error.HTTPError as e:
    print('HTTP', e.code)
```

## 3. What you should see

- **Expected difference:** If the finding is real, the reader receives 200 and an owner_id that is not theirs. If it is fixed, the reader receives 403 or 404.
- **Decision rule:** Finding present if and only if status == 200 and body.owner_id != the reader's own id.
- **After the fix:** Run the same replay as the reader: expect 403 or 404. Run it as the owner: expect 200.
